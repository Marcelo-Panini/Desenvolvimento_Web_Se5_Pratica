# 📚Resumo:
A disciplina foca na combinação de princípios de design visual com tecnologias web para criar interfaces funcionais e atraentes.

Principais Conceitos Discutidos:
- **Controle de Versões:** Essencial para registrar alterações, recuperar versões específicas e permitir a colaboração em equipe através de ramificações;
- **Plataformas de Versionamento:** GitHub, GitLab e Bitbucket;
- **Vanilla JS:** Uso do JavaScript puro, sem dependências externas, fundamental para a lógica de interface e manipulação de páginas.
- **CMS e Website Builders:** Ferramentas como WordPress, Wix e Webflow que permitem a criação de sites com rapidez, embora possuam limitações de flexibilidade e performance;
- **Frameworks:** Introdução à arquitetura de ferramentas como React, Vue e Angular (Front-end) e padrões como MVC e RESTful APIs (Back-end).

## 💼Importância do Portfólio
O desenvolvimento de um portfólio é tratado como evidência concreta de aprendizado, sendo vital para a preparação para desafios do mercado profissional e processos de estágio.

## 📊 Critérios de Avaliação
O sistema de notas e as avaliações foram divididos em quatro partes principais:

**AC1 (15%):** Prova escrita de múltipla escolha focada na teoria e aplicação dos conceitos.
**AC2 (30%):** Entrega e apresentação de um projeto prático em grupo (3 a 5 integrantes).
**Avaliação Geral (10%):** Nota complementar da média.
**Avaliação Final (45%):** Entrega da documentação completa do projeto, estruturada como um "mini TCC".
